# الاتصال الداخلي — Local Walkie-Talkie & Intercom

تطبيق أندرويد (Kotlin + Jetpack Compose) للاتصال الصوتي بين موظفي الشركة عبر **شبكة الواي فاي المحلية** بدون إنترنت أو شريحة.

## المميزات

- اكتشاف تلقائي للزملاء على نفس الشبكة (NSD / mDNS) مع الاسم والوظيفة والحالة.
- **Push-To-Talk**: تحدث لزميل واحد أو **بث للجميع**.
- **مكالمة صوتية ثنائية** (رنين، رد، رفض، إنهاء، عدّاد مدة).
- حالة الموظف (متاح / في اجتماع / مشغول / غير متواجد). في "اجتماع" يُكتم الوارد وتُرفض المكالمات.
- يعمل في الخلفية عبر Foreground Service (يستقبل والشاشة مطفأة).
- واجهة Material 3 عربية RTL، فاتحة/داكنة تلقائياً.

## بناء ملف APK

### الطريقة 1: Android Studio
1. افتح مجلد المشروع في Android Studio (Ladybug أو أحدث) وانتظر Gradle Sync.
2. من القائمة: **Build ▸ Build Bundle(s) / APK(s) ▸ Build APK(s)**.
3. الملف يظهر في `app/build/outputs/apk/debug/app-debug.apk`.

### الطريقة 2: سطر الأوامر (JDK 17 + Android SDK)
```
./gradlew assembleDebug
```

### الطريقة 3: بدون تثبيت أي شيء (GitHub Actions)
ارفع المجلد كاملاً على مستودع GitHub جديد، ثم افتح تبويب **Actions ▸ Build APK ▸ Run workflow**.
بعد دقائق نزّل `LocalWalkie-apk` من قسم Artifacts.

## التثبيت
انسخ الـ APK للهاتف وافتحه (فعّل "التثبيت من مصادر غير معروفة" إن طُلب). عند أول تشغيل: امنح إذن الميكروفون والإشعارات، ثم أدخل اسمك ووظيفتك.

## الاختبار
تحتاج **جهازين على الأقل** على نفس شبكة الواي فاي.
> لو الراوتر يفعّل **AP Isolation / Client Isolation** (شائع في شبكات الضيوف) فلن يرى الأجهزة بعضها — عطّله أو استخدم شبكة الموظفين.

## هيكل الكود

| الملف | الوظيفة |
|---|---|
| `net/PeerDiscovery.kt` | نشر خدمة NSD واكتشاف الزملاء (بيانات الملف الشخصي في TXT) |
| `net/UdpTransport.kt` | مقبس UDP واحد + تعريف البروتوكول (صوت 16kHz، إطار 20ms) |
| `audio/Capture.kt` / `Playback.kt` | التقاط الميكروفون (مع AEC وكتم الضوضاء) وتشغيل الوارد |
| `core/IntercomController.kt` | ربط كل شيء + منطق المكالمات وقفل المتحدث |
| `service/IntercomService.kt` | الخدمة الأمامية والإشعارات |
| `ui/*` | شاشات Compose |

## تطويرات مقترحة
- ضغط الصوت بـ **Opus** لتقليل استهلاك الشبكة.
- تشفير الحزم بـ **AES-GCM** بمفتاح مشترك للشركة (حالياً الصوت غير مشفّر على الشبكة المحلية).
- مكالمات جماعية (مزج الصوت أو WebRTC).
